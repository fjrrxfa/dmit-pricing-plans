- $119.99/年 ≈ $10.00/月
- $159.98/年 ≈ $13.33/月
- $203.9/年 ≈ $16.99/月
- $298.88/年 ≈ $24.91/月

**AN4 和 AN5 的差价，只有 CPU 在变。** 同样是 Pro.TINY、同样的 1 核 2GB / 20GB / 1000GB / 1Gbps、同样的三网 CN2 GIA 回程，AN4 是 $88.88/年，AN5 是 $119.99/年，一年贵 **$31.11，约 35%**。Pocket 档从 $159.98 涨到 $203.9，贵 **$43.92，约 27%**。差别在处理器：AN4 用 EPYC 9004，AN5 用 EPYC 9005，第三方说法是单核性能大约 1.5 倍。

## Pro、EB、T1 三条线路，选错比买贵更亏

DMIT 全系跑在 KVM + AMD EPYC 上，硬盘都是 NVMe/SSD，机房只有洛杉矶、香港、东京三个。真正拉开价格的是线路：

**Premium（Pro）** 是旗舰档，电信走 CN2 GIA、联通走 AS9929、移动走 CMI/CMIN2，回程也是 CN2 GIA，自有骨干上 CN2 GIA 给了 40Gbps、9929 和 CMIN2 各 20Gbps。第三方评测记录里，洛杉矶 Premium 晚高峰丢包率低于 0.1%，非高峰平均延迟约 160ms 上下，晚高峰没有出现延迟飙升。这个数据来自评测站，不是我实测的，但方向可以信。

**Eyeball（EB）** 是性价比档，回程走 9929 / CMIN2 一类优化线路，价格比 Pro 略低，联通移动体验反而更均衡。

**Tier 1（T1）** 是纯国际线路，没有中国大陆专项优化。晚高峰绕路、延迟飙到 300ms 以上都是正常现象，这不是 DMIT 的问题，是国际线路本身的性质。T1 适合用户在海外的建站、跑脚本、做落地中转，不适合直接给国内用户提供访问服务。

三条线路各自的“不适合谁”也说清楚：

- **Pro 不适合**只跑轻量任务、对延迟没要求的人，多付的钱买不到你能感知的差别
- **EB 不适合**对回程质量要求极致、或者只认 CN2 GIA 三个字的电信老用户
- **T1 不适合**任何以国内访问为主的场景。为了省几十美元选 T1，然后每天晚高峰卡到怀疑人生，是这类选购里最常见的错误

机房位置按延迟记：香港 30–50ms，洛杉矶 150–200ms，东京在中间。

## 下单前必须知道的六个坑

**1. WEE 只卖年付，而且限量。** 三地的 WEE 都是年付专属，没有月付可选，库存补上后常常几小时内售罄。想用 WEE 就只能一次付一年，没有“先买一个月试试”这条路。

**2. SSH 私钥只能下载一次。** DMIT 不支持密码登录，首次开机必须下载私钥，而且这个下载机会只有一次。文件丢了只能重装系统或者提工单，是新人最容易卡住的一步。下单前先把私钥存好。

**3. 不支持 Windows。** 只提供 Ubuntu、CentOS、Debian 这些 Linux 发行版。要跑 Windows 程序的，这台机器从第一步就不合适。

**4. 换 IP 政策分档。** Pro 和 EB 系列每 15 天可以免费换一次（需满足条件），T1 系列换一次 **$5**。2026 年初起支持在控制台自助换 IP，不用提工单等客服。购买时还可以加 IP Guarantee+，开机就保证 IP 可用，不加的话遇到被墙的 IP 要自己走流程。

**5. 流量超了不停机，改成限速。** LAX T1.WEE 超量后限速 100Mbps 继续跑，HKG 和 TYO 的 T1.WEE 限速 50Mbps。对跑大流量任务的人来说，这比直接关机友好得多。

**6. Pro 和 EB 的常规款多是月付、季付，年付要等特价补货或促销期。** T1 系列基本全线有年付。想买 Pro 的年付价，得碰上补货；买不到就按季付走，别硬等。

**$36.9 的 WEE 适合什么人？**

适合预算有限、用途轻量的场景：跑脚本、做备用节点、面向海外的静态站、配合现有方案做落地。1 核 1GB 内存，装个面板加小站勉强够用，跑重一点的业务就吃力了。它不适合直接给国内用户提供访问服务，因为 T1 线路没有大陆优化。

**AN4 还是 AN5？**

线路完全一样，都是三网 CN2 GIA 回程，只差 CPU 平台。预算敏感选 AN4，$88.88/年；需要单核性能选 AN5，$119.99/年。只做网络转发的话，这 31 美元的差价买不到任何东西。

**IP 被墙了怎么办？**

Pro 和 EB 每 15 天可免费换一次，T1 每次 $5。2026 年起可以自己在控制台操作。买的时候勾上 IP Guarantee+ 能省掉开机就被墙的麻烦。

**有没有优惠码？**

截至 2026 年 4 月，没有已核验的常规有效优惠码在流通。历史上的折扣集中在黑五、春节、圣诞这类节点，形式是直接折扣加账户余额返还。结算页有 Promo Code 输入框，填之前先确认码还在有效期内，过期的码验证会直接失败。

**能升级配置吗？支持哪些系统？**

支持套餐升级，降级需要重新购买。系统只有 Linux 发行版，没有 Windows。
